# macOS config

This folder holds the macOS-specific dotfiles ported from the older Linux setup.

## Files

- `.zshrc`
- `.tmux.conf`
- `ghostty/config`

## Suggested symlinks

- `~/.zshrc -> <repo>/mac/.zshrc`
- `~/.tmux.conf -> <repo>/mac/.tmux.conf`
- `~/.config/ghostty/config -> <repo>/mac/ghostty/config`
